# Hearth

A cozy, dark, fully customizable book reader for Android phones and tablets.

**Private by design:** no internet permission, no ads, no tracking, no cloud backup. Optional app lock (fingerprint / face / PIN) and privacy screen (blocks screenshots and recent-apps preview) in Settings.

**Download:** open the [latest release](../../releases/latest) and tap `Hearth.apk`.

Every push to `main` builds a new APK automatically (GitHub Actions).
